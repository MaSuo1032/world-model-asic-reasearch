# 可手算的完整範例：32列動作，4輪去噪

日期：2026-10-12｜作者：GPT｜[回主文件](README.md)

**這是全部權重、輸入均已知的教學模型，不是訓練後的Flex-π預測。** 保留32列action、觀測K/V、self-attention、文字/state cross-attention、LayerNorm、Q/K RMSNorm、RoPE、GELU FFN、gate、線性輸出頭、4輪Euler與反正規化；將hidden/action維度縮成2、head數縮成1、層數縮成1。該層代表會讀觀測的middle layer，不另加outer layers。VAE/DINO輸入改由明列的已編碼觀測特徵開始，真實像素編碼按[encoders.md](encoders.md)。

此範例用人工指定初始樣本，不宣稱這些64個值是由某個seed抽到的Gaussian。真實模型為32×14、30層，不能把以下32×2數字當成機器人的命令。

## 1. 完整輸入與簡化的時間函數

觀測anchor共3列：`[[1,0],[0,1],[-1,1]]`。其RoPE角度明定為 `[0,0.5,1]` radians。這三列已是本例的visual hidden，不另做未說明的encoder。

文字context一列 `[0.3,-0.2]`。state原始值 `[0.5,-0.4]`，mean `[0.1,-0.2]`，std `[0.2,0.4]`，按含10⁻⁸與±5裁切的公式正規化，得到 `[1.999999900000005,-0.4999999875000003]`。proprio encoder與context projector在本例均明定為identity、bias0，因此context共2列，全True mask。

初始動作逐列：

```text
A0[i] = [0.2+0.01i, -0.1+0.005i], i=0…31
```

例如第0列 `[0.2,-0.1]`、第31列 `[0.51,0.055]`。每一列action的RoPE角度是 `i` radians，同一輪32列全可見。

為免藏著未知time MLP，本例直接指定六組調變，兩個channel使用相同值：

```text
shift_sa=0；scale_sa=0.1σ；gate_sa=0.5+0.1σ
shift_ff=0.02σ；scale_ff=-0.05σ；gate_ff=0.25+0.1σ
```

prefill用σ=0；action四輪σ=1、0.75、0.5、0.25。這是教學時間函數，真實模型必須用主文件的sinusoidal embedding、time MLP與每層modulation。

所有LN ε=10⁻⁶，norm1/norm2沒有affine。norm3 γ=[1.1,0.9]、β=[0.01,-0.02]。所有Q/K RMS ε=10⁻⁶、weight=[1,1]。head_dim=2，所以attention除√2。

## 2. 逐步手算方法

先用主文件§5公式對3個觀測anchor做一次block，保存attention-input的3列K/V。這一層之後沒有第二層，所以prefill post-block的hidden不再使用，cache仍取投影時的K/V。

每一輪：

1. `X=Linear(A,enc)`，得到32×2。
2. 每列算LN、time modulation、Q/K/V，再算RMS與RoPE。
3. K/V順序為 `[3個cached anchors ; 本輪32個actions]`，一共35列。
4. 每個query對35列做softmax，得到self attention，再O投影＋gate residual。
5. norm3後，對2個context列做cross attention，O投影後直接加回。
6. norm2＋FFN調變→2→3→2的GELU FFN→gate residual。
7. head Linear得到32×2的速度。全部元素同時減0.25倍速度。
8. 按更新後的32列重新跑下一輪。

所有Linear都用 `Σ W[out,in]x[in]+bias[out]`，矩陣方向固定。以下表格列出所有權重、cache、第一列第一輪細節、4輪更新以及全部32列最後結果。
