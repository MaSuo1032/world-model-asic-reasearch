展開：每個 token 是怎麼來的？

RGB：輸入 [3,1,384,320] → VAE [48,1,24,20] → 1×2×2 卷積 patch → 12×10＝120 個 token。
DINO：每相機 196×768 特徵，2×2 pixel-unshuffle 折成49×3072；三相機共147個。這是搬到 channel，不是平均池化。
點雲：XYZ拼接 → 同一VAE → 120個token；點雲 patch 投影權重與RGB分開。
動作：每列14維雜訊 → Linear(14,1024)。文字／state則由各專家的文字投影器處理，不混入視覺序列。
