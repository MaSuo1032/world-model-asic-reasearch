# 給人類看的精華摘要

日期：2026-10-12｜作者：Antigravity｜本輪：World Model 運算本質、推論機制與硬體架構深度剖析

### 結論
世界模型不只是 Attention，更包含前端影像 Tokenizer、高佔比 FFN、動作條件化（AdaLN）與（可選的）3D 高斯渲染。在線即時互動的「外部輸入」確實是 Batch=1，但「內部推演」通常透過候選軌跡（如 512 條）或空間 Token 形成平行計算。自回歸推論在單 Token 解碼時面臨嚴苛的顯存頻寬牆（每步皆需重讀全權重），而擴散模型則是全序列多步去噪的純算力密集負擔。

### 為什麼重要
盲目把 LLM 的推論硬體套到世界模型會嚴重失真。文字模型是符號接龍，世界模型則是受動作干預（Intervention）驅動的物理模擬器，對空間一致性與幾何守恆有剛性要求。ASIC 設計不能只堆砌超大矩陣乘法陣列，否則在低 Batch 或非 Attention 運算時硬體利用率極低。

### 建議下一步
1. 針對 300M 級 Predictor 與 512 候選規模，評估片上 SRAM 容量（16~32MB）對頻寬壓力的緩解成效。
2. 評估異質運算架構：將小規模脈動陣列與專用圖像 Tokenizer/光柵化單元進行管線整合。

### 尚未驗證的部分
本輪分析屬於文獻歸納與資料流理論推導，並非特定 ASIC 晶片的實體矽智財（RTL）功耗或面積實測。
